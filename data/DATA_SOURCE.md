# 数据来源说明

## 数据口径（先看这段）

| 数据 | 来源 | 规模 | 价格口径 |
|---|---|---|---|
| 房源主表 `house_info` | 链家北京二手房公开快照 CSV（`data/datasets/lianjia_bj_20220730/0814/0826.csv`），合并去重 | 38,267 条 | **总价（万元）+ 挂牌单价（元/㎡）**，不是月租 |
| 租房样例 | `data/datasets/mysql_house_data.csv`（链家 / 我爱我家） | 126 条 | 月租（元/月），含房东、房源编号 |
| 手工示例 | `app/services/seed_data.py` | 12 条 | 示例价格，小区名与坐标真实 |
| 交互与评论 | `seed_simulated_data.py` 生成 | 40 个模拟用户 + 评论/收藏/浏览/对比 | — |
| 向量索引 | 房源**全量**入库（`rag_house_index_limit=40000` ≥ 库内总数即全量） | 38266 个**房源**片段（`type=house`，覆盖 4900 个小区、13355 个「小区 × 户型」组合）；文档型向量 0 条，需管理员上传文档后生成 | — |

> 对外说明口径：**"公开挂牌快照 + 示例化价格，小区名和经纬度真实"**；不宜宣称"3.8 万套真实成交"，也不要把主表说成租房月租数据。

## 房源数据

本系统使用的房源数据基于以下真实信息来源：

### 小区名称与地理位置
- **数据来源**：北京市公开的住宅小区信息 + 高德地图地理编码
- **小区列表**（12个真实北京小区）：
  1. 三里屯SOHO公寓（朝阳区三里屯街道）- 116.4551, 39.9370
  2. 华清嘉园（海淀区中关村街道）- 116.3378, 39.9932
  3. 金融街金宸公寓（西城区金融街街道）- 116.3603, 39.9139
  4. 建外SOHO（朝阳区建外街道）- 116.4613, 39.9087
  5. 龙泽苑小区（昌平区回龙观街道）- 116.3412, 40.0683
  6. 望京SOHO（朝阳区望京街道）- 116.4772, 39.9936
  7. 清枫华景园（海淀区学院路街道）- 116.3513, 40.0032
  8. 亦庄金茂悦（大兴区亦庄地区）- 116.5042, 39.7928
  9. 汇欣公寓（朝阳区亚运村街道）- 116.3968, 39.9923
  10. 万达广场公寓（通州区新华街道）- 116.6573, 39.9092
  11. 丽泽景园（丰台区卢沟桥街道）- 116.3215, 39.8623

### 经纬度坐标
- **数据来源**：高德地图地理编码 API（公开坐标拾取工具）
- **坐标系**：GCJ-02（国测局加密坐标，高德地图使用）

### 房源价格（二手房挂牌口径）
- **数据来源**：链家北京二手房公开快照（`lianjia_bj_20220730.csv` / `lianjia_bj_20220814.csv` / `lianjia_bj_20220826.csv`，各约 4.5 万行，合并去重后 38,267 条）
- **字段**：总价（万元）、挂牌单价（元/㎡）、户型、面积、朝向、装修、楼层、建成年代、房源链接
- **说明**：价格为挂牌价快照，非成交价，已做示例化处理

### 租房样例数据
- **数据来源**：`data/datasets/mysql_house_data.csv`（链家 / 我爱我家，126 条）
- **字段**：月租（元/月）、房东、联系电话、房源编号等，用于租房场景演示

### 房源配套设施
- **数据来源**：基于真实租房平台常见配套设施分类整理

### 交通信息
- **数据来源**：北京地铁公开线路信息 + 真实站点位置
- **说明**：步行距离为参考估算值

## 地图服务

- **地图提供商**：高德地图（Amap）
- **API 文档**：https://lbs.amap.com/api/
- **使用方式**：需申请高德开放平台 API Key，配置到前端页面中

## 数据使用声明

1. 本系统为演示项目，数据仅供学习和研究使用
2. 小区名称、地理位置、交通信息为真实公开信息
3. 具体租金、房东信息、联系方式为示例数据，非真实可交易房源
4. 地图服务由高德地图提供，需遵守高德地图 API 使用条款

## 数据扩展

如需扩展更多真实房源数据，可通过以下方式：
1. 爬虫采集公开租房平台数据（需遵守 robots 协议）
2. 使用高德地图 POI 搜索 API 获取更多小区信息
3. 对接链家、贝壳等公开数据 API（如有授权）
